# Egg Command Battle

卵を奪い、配合し、コマンドで戦う。ブラウザで動く個人開発のゲーム。

## まず、どれを押すか

| したいこと | 押すもの |
|---|---|
| **遊ぶ** | `ゲームを開く.bat` → `http://localhost:5817/app` |
| **画面の配置を直す** | `エディタを開く.bat` → `/edit` |
| **図鑑（技・種族の一覧）を見る** | `図鑑を開く.bat` |

⚠️ `http://localhost:5817/` は**ゲームではなく図鑑**です。遊ぶのは `/app`。
⚠️ ⭐ **建て直したらサーバも入れ直す。**走ったままだと古い資産名を配り続け、
ブラウザが 404 ＋ SRI 失敗で真っ白になります。

## どこに何があるか

| 場所 | 中身 | 触るとき |
|---|---|---|
| `game/` | ゲーム本体（C# / .NET 9 / Blazor WebAssembly）| 仕組みを変えるとき |
| `assets/` | 🔴 **中身の唯一の出所** ── 骨組み・絵・字 | 画面や絵を変えるとき |
| `art/` | ドット絵の元データと、焼いた PNG | キャラを描いたとき |
| `sheets/` | 技・特性・種族を**手で書く**帳面（`sim sheet`）| 内容を足すとき |
| `tools/` | 動いているゲームを外から叩く検査（node）| 直したあと確かめるとき |
| `wiki/` | 攻略Wiki。`wiki/開発/` が開発ノート | 決めごとを書くとき |
| `参考/` | 他作品の調査・モック | 見比べるとき |
| `old/` | ⚠️ **動かしていない。残してあるだけ** | 原則さわらない |

### `game/` の中

| | |
|---|---|
| `EggCommand.Core` | 🔴 **遊びの規則**（戦闘・配合・乱数・保存）。画面を1行も知らない |
| `EggCommand.Web` | 画面。DOM の絶対配置で描く。骨組みエディタもここ |
| `EggCommand.Sim` | 道具（図鑑を書く・絵を焼く・決定性を検査する）|
| `EggCommand.Tests` | 検査 855件（`dotnet test`）|

### `assets/` の中

| | |
|---|---|
| `layouts/*.txt` | 画面の配置（33枚）。⚠️ **座標はここにしか書かない**（コードに書かない）|
| `ui/` | 絵。`icon/` は小さな記号、`paint/` は背景と部品 |
| `fonts/` | ドット字（PixelMplus10）。⚠️ ライセンスは同じ場所の `NOTICE.md` |

⚠️ `game/EggCommand.Web/wwwroot/` の下の `fonts` `icon` `ui` `paint` `sprite` は
**毎ビルドの写し**です（版管理に入れない）。直すなら `assets/` と `art/` のほう。

## 土台（変えるときは覚悟して変える）

| | |
|---|---|
| 画面 | 設計座標 **1080×1920** 固定。実機へは**整数倍だけ**で拡大し、余りは黒帯 |
| 升目 | **270×480 ドット**（1ドット＝設計 4px）。座標は**4の倍数** |
| 絵 | 🔴 **拡大縮小しない。**枠は「ドット数×4」。合わないものは**警告する** |
| 字 | PixelMplus10 / **40px**（10の倍数以外はにじむ）|
| 骨組み | 🔴 `Layouts.Write(Layouts.Parse(x)) == x`（**往復のバイト忠実**）|
| 乱数 | 種から。`Math.random()` 禁止 |

くわしくは [wiki/開発/技術と運用.md](wiki/開発/技術と運用.md) と
[wiki/開発/ドット絵化計画.md](wiki/開発/ドット絵化計画.md)。
