# 特性 aim
名前 = 狙い澄まし
働く場面 = 常時
すること = 弱化が通る率が上がる
噛み合うもの = 呪詛・スピードDOWN・全体・スタン・大。⭐ **通りにくい技ほど得**なので、博打側の技と組む

# 特性 stubborn
名前 = 意地
働く場面 = 常時
すること = 弱化を受ける率が下がる
噛み合うもの = 相手の弱化役を腐らせる。⚠️ 相手に弱化役がいないと何もしない

# 特性 spite
名前 = 返し身
働く場面 = 攻撃を受けたとき
すること = 受けたダメージの一部を返す
噛み合うもの = 挑発・受けの構え。⭐ **わざと殴られる**動きが得になる

# 特性 grit
名前 = 執念
働く場面 = シールドが剥がれたとき
すること = シールドが剥がれるたびゲージが溜まる
噛み合うもの = シールド・大・硬化・シールド。⭐ シールドを「守り」から「手数の元」に変える

# 特性 flurry
名前 = 手数
働く場面 = 攻撃を当てたとき
すること = 多段の1発ごとに技の待ちが縮む
噛み合うもの = 連撃・乱打。⚠️ 単発の技しか持っていない個体では死ぬ

# 特性 leech
名前 = 食らいつき
働く場面 = 攻撃を当てたとき
すること = 与えたダメージの一部を吸う
噛み合うもの = 攻撃役の自己完結。⭐ 回復役を1枠空けられる

# 特性 opener
名前 = 先駆け
働く場面 = 戦闘開始時
すること = 戦闘の最初の1手で弱化が外れない
噛み合うもの = スピードDOWN・全体・呪詛・スタン・大。⭐ **外れうる弱化ほど得** ── 開幕に1つだけ確実に通せるので、通りにくい札を先に切る判断が生まれる

# 特性 parting
名前 = 置き土産
働く場面 = 倒れる一撃を受けたとき
すること = 倒れたとき、残った味方のゲージが進む
噛み合うもの = 挑発・蘇生。⭐ 先に倒れる役が損で終わらなくなる。⚠️ 味方が残っていないと何もしない

# 特性 pursuit
名前 = 追い打ち
働く場面 = 攻撃を当てたとき
すること = 弱化が付いた相手に与えるダメージが増える
噛み合うもの = 毒・呪詛・スピードDOWN・全体。⭐ **弱化を置いてから殴る**という手順が火力になる

# 特性 desperation
名前 = 背水
働く場面 = 常時
すること = 自分のHPが半分以下の間、技の待ちが速く減る
噛み合うもの = 全体連撃・スタン・大・蘇生。⭐ **重い技を持たせる理由**がここで生まれる ── 低空を保つほど手数になるので、待ちの長い札と噛み合う。⚠️ 回復役に戻されると条件が消える

# 特性 surge
名前 = 畳み掛け
働く場面 = 弱化を通したとき
すること = 弱化を通すと、その戦闘で一度だけすぐもう一度動ける
噛み合うもの = 呪詛・毒・スタン・スピードDOWN。⭐ **通す確率に投資するほど早く来る**ので、弱化命中の高い個体・狙い澄まし・属性有利と重なる

# 特性 ambush
名前 = 不意打ち
働く場面 = 相手が手番を飛ばしたとき
すること = 相手が手番を飛ばすたび、自分のゲージが進む
噛み合うもの = スタン・スタン・大・眠り・痺れ打ち。⭐ **止めてから動く**という手順が、そのまま自分の手数に変わる。⚠️ 止める技を持たない編成では何も起きない

# 特性 legacy
名前 = 遺志
働く場面 = 味方が倒れたとき
すること = 味方が倒れると、自分の技の待ちがすべて消える
噛み合うもの = 全体強攻撃・蘇生・挑発。⭐ **重い技をもう一度撃てる**ので、崩れてからが本番になる。⚠️ 誰も倒れない編成では死に特性

# 特性 tenacity
名前 = 粘り腰
働く場面 = 常時
すること = 自分のHPが半分以下の間、受け取る回復が増える
噛み合うもの = HP割合回復・リジェネ・立て直し。⭐ **回復役を連れているか**が編成の判断になる。⚠️ 回復を持たない編成では何も起きない

# 特性 mirror
名前 = 写し身
働く場面 = 相手が強化を得たとき
すること = 相手が強化を得たら、自分にも同じ強化が乗る
噛み合うもの = 強化解除・強化強奪・意地
メモ = 場面が新しい。持続は相手と同じで、重ねがけは上書きでよい
