## 製図（CAD のような下ごしらえ）

「色をつくる・描き方」の窓 →「製図」。⚠️ **絵ではないので `.pixelizer.json` に混ざらない**
（あれは `sim import-screen` が読む形なので勝手に増やさない）。好みは localStorage に覚える。

| | 何をするか |
|---|---|
| **中心線** | キャンバスの中心に**一点鎖線**（CAD と同じ書き方）。⚠️ 実線にすると絵の一部に見えるので鎖線 |
| **目盛りの線** | なし / 8 / **10（字1行ぶん）** / 16 / **28（押しどころの下限）**。1ドットの方眼より濃く引く |
| **読み取り** | 左下に出る。⭐ **ドット数と設計 px を両方**出す |

⭐ **読み取りが出すもの**:

```
画布 270×480 (1080×1920px)
位置 135, 240
範囲 79×28 (316×112px)
範囲 79×20 (316×80px) ⚠ 押しどころなら 28 未満
```

⭐ **数えなくてよくなるのが要点。**選んだ範囲がそのまま骨組みの枠になるので、
ここで見た `79×28` が `316 112` として骨組みに出る（`sim import-screen` が ×4 する）。

⚠️ **28ドット（112px）** を下回ると指で押しにくい ── 押しどころを囲っているときは警告が出る。

### 製図モード ── CAD のドットバージョン

「四角」「直線」「円」を押すと、専用の**図形レイヤー**（無ければその場で作る）が
アクティブになる。⭐ **図形レイヤーを選ぶこと自体が製図モード**（別のモード切替は無い ──
普通のレイヤーに戻れば手書きモードに戻る）。

⭐ 置いた図形は**焼かない・なぞる下敷き専用**。最終的な絵は必ず手書きモードでなぞる。
🔴 **専用のレイヤーとして保存される**（`.pixelizer.json` の書き出し・アプリ内保存の
両方に自動で乗る）── くわしくは [製図モード](../../wiki/開発/製図モード.md)。

| | 何をするか |
|---|---|
| **選ぶ** | 図形を押すと選ばれる。数値（x/y/w/h）を直で打ち直せる |
| **動かす** | 本体をドラッグ。スナップつき |
| **変形** | 選んだ図形の隅（矩形/円）・両端（直線）のハンドルをドラッグ |
| **消す** | 選んで Delete キー、または「選んでいる図形を消す」 |
| **オフセット** | ドット数を打つと、外側/内側にずらした**新しい図形**を作る（元は残す）|
| **並べる（ARRAY）** | 列・行・間隔を打つと、その並びで複製する |
| **スナップ** | 格子・ガイド・端点・中点・中心・接点（円が外接する矩形と接する4点）を種類ごとに ON/OFF |

⚠️ `sim import-screen` は図形レイヤーを「製図モードの下敷きなので取り込みません」と
案内して静かに読み飛ばす（他のレイヤーの取り込みは止めない）。

### 補助線 ── 好きな所に引ける

「縦ガイド」「横ガイド」を押すと**置くモード**になり、キャンバスを押した場所に緑の破線を引く。
⚠️ 置くモードの間は鉛筆で描かない（置くのが先）。もう一度押すか、別の道具を選ぶとやめる。
一覧のチップ（例:「縦 60 ×」）を押すと1本ずつ消せる。「補助線を全部消す」で一括。

🔴 **見え方の好み（`draft`）と同じ扱い ── 絵ではないので `.pixelizer.json` に入らない。**
キャンバスの大きさに紐づく参考線（「ここがタブ帯の上端」等）として、
どの画面を描いていても同じ補助線が出るようにしてある。

### 太さ（鉛筆・消しゴム）

「描き方」の下に 1/2/3/4/6/8 ドットの釦。⭐ **正方形のスタンプ**（偶数は右下へ寄る）。
⚠️ 2ドット以上のときは「かど消し」を使えない（角の巻き戻しが1マスしか戻さないので、
太い線の途中で使うと**線の中に穴が空く**）。太くすると自動で切れる。

## この道具でやること

⭐ 画面を **270×480 のキャンバスに 0 から置いていく**。
できたら「そのほか」→ ファイルに書き出す → `art/screens/<画面名>.pixelizer.json`。

```
cd game
dotnet run --project EggCommand.Sim -- import-screen art/screens/home.pixelizer.json
dotnet run --project EggCommand.Sim -- paint-placeholder
```

レイヤー名の約束（**この道具はまだ知らない。`sim` 側だけが知っている**）:

| レイヤー名 | どうなるか |
|---|---|
| `home-mats` | `assets/ui/paint/home-mats.png` になる（透明でない範囲で切り出し）|
| `_tap-trial` | 🔴 絵にしない。押しどころ（`button`）の**場所だけ**が骨組みへ |
| `_exp` | 🔴 絵にしない。字の入る場所（`label`）の**場所だけ**が骨組みへ |
| `Layer 3`（名前の付け忘れ） | ⚠️ 何も出ない。取り込みのときに言われる |

くわしくは [画面をドット絵で組む](../../wiki/開発/画面をドット絵で組む.md)。

## これから足せそうなこと（まだやっていない）

⚠️ **要ると分かってから足す。**先回りして作らない。

| | なぜ効くか |
|---|---|
| レイヤー名の候補を出す | 約束（`_tap-` など）を覚えなくて済む。いまは `sim` に怒られて初めて気づく |
| いまの骨組みを薄く重ねる | `assets/layouts/*.txt` を読んで、既にある配置の上に描ける |
| `assets/ui/paint/` へ直に書く | `.pixelizer.json` を経由せず、描いたその場でゲームに反映 |
| ゲームの 12 色を色見本に入れる | `stage.css` の定数。画面の色が勝手に増えないようにする |
| GIF まわりを外す | 画面は動かない。`gif.js` ごと落とせば同梱物が減る |
| 補助線をドラッグで動かす | いまは置くだけ・消すだけ。位置を微調整したいときは一度消して置き直す |
| 円形の太さ | いまは正方形のみ。斜め線で角が立つのが気になったら |
| 図形の前面へ/背面へ | いまは「後から置いたものが手前」固定。並べ替えたくなったら |
| 交点スナップ | 線と線・線と円が交わる点。2図形の組み合わせ計算が要るので保留にした |
| 図形の重なりに矢印キーの微調整 | いまはドラッグのみ。1ドット単位で追い込みたくなったら |
