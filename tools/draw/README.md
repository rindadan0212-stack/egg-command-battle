## この道具でやること

⭐ 画面を **270×480 のキャンバスに 0 から置いていく**。
できたら「そのほか」→ ファイルに書き出す → `art/screens/<画面名>.pixelizer.json`。

```
cd game
dotnet run --project EggCommand.Sim -- import-screen art/screens/home.pixelizer.json
dotnet run --project EggCommand.Sim -- paint-placeholder
```

レイヤー名の約束（**この道具はまだ知らない。`sim` 側だけが知っている**）:

| レイヤー名 | どうなるか |
|---|---|
| `home-mats` | `assets/ui/paint/home-mats.png` になる（透明でない範囲で切り出し）|
| `_tap-trial` | 🔴 絵にしない。押しどころ（`button`）の**場所だけ**が骨組みへ |
| `_exp` | 🔴 絵にしない。字の入る場所（`label`）の**場所だけ**が骨組みへ |
| `Layer 3`（名前の付け忘れ） | ⚠️ 何も出ない。取り込みのときに言われる |

くわしくは [画面をドット絵で組む](../../wiki/開発/画面をドット絵で組む.md)。

## これから足せそうなこと（まだやっていない）

⚠️ **要ると分かってから足す。**先回りして作らない。

| | なぜ効くか |
|---|---|
| レイヤー名の候補を出す | 約束（`_tap-` など）を覚えなくて済む。いまは `sim` に怒られて初めて気づく |
| いまの骨組みを薄く重ねる | `assets/layouts/*.txt` を読んで、既にある配置の上に描ける |
| `assets/ui/paint/` へ直に書く | `.pixelizer.json` を経由せず、描いたその場でゲームに反映 |
| ゲームの 12 色を色見本に入れる | `stage.css` の定数。画面の色が勝手に増えないようにする |
| 押しどころの下限（28ドット）を格子で示す | 指で押せない大きさをその場で気づける |
| GIF まわりを外す | 画面は動かない。`gif.js` ごと落とせば同梱物が減る |
