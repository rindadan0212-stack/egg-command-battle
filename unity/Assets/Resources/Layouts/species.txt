# 種族1つの中身 ── ⭐ 特性と、技枠の抽選内容
#
# ⚠️ **属性は出さない。**属性は卵ごとに引くので、種族の性質ではない（書くと嘘になる）。
# ⚠️ **★も出さない。**★は卵の側の話。
#
# ⭐ 技は**長押しで効果**。⚠️ 押すだけでは何も起きない ── ここは読む場所で、選ぶ場所ではない。
#
# ⭐ **`flow=down` の初実戦。**⚠️ 技の袋は 1〜5種と長さが変わるので、
#    下の塊の位置を書けない。詰める親の中では `上` が「その上に空ける隙間」になる。
#
