# アプリの外枠 ── ⭐ 下の帯だけ（**どの画面にも付く**）
#
# ⭐ 帯は**常設のタブバー**（2026-08-20・作者の指示）。
# ⚠️ ただし戦闘と潜入では出さない ── そこから抜けられると、
#    不利な盤面をいつでも無かったことにできてしまう。
#
# 🔴 **上のバー（`top`）を丸ごと外した**（2026-08-29・作者の指示「この帯は不要」
#    ／戦闘の帯も「常に消す・ボス名は捨てる」）。⚠️ 外枠は全画面共通なので、
#    ここを消すと**どの画面も 132px ぶん上に詰まる**（`AppPage` の `#app-body` が
#    `top:132` → `top:0`・丈 1556 → 1688）。これが作者の言う「上に詰める」。
#
# ⭐ 乗っていた4つの行き先:
#    ・`title`（題名）── **捨てた**。画面の中身を見れば分かる字だった。
#      ⚠️ ボス戦のボス名もここに出ていたが、作者の判断で捨てる。
#    ・`back`（‹）── **捨てた**。出していたのは図鑑と試練の2画面だけで、
#      どちらも下の帯（ホームのタブ）が同じ行き先を持っている＝重複した道だった。
#    ・`badge`（EXP）── BOX と配合の**画面の中**へ移した（`box.txt`／`breed.txt` の
#      いちばん下）。⭐ 上のバーが消えて空いた 1556〜1688 に置ける。
#    ・`extra`（右肩の入口）── ホームの「図鑑」は**右上のメニュー**（`menu.txt`）へ、
#      探索の「パーティ編成」は`nests.txt` の下端へ移した。
#
# ⚠️ `dock=no` ＝ 下の帯を跨いでよい印。⭐ 帯そのものにしか付けない。
#
#  名前    種類    左   上    幅   高    付け足し

# ⭐ 2026-08-25 ドット絵化 段取り4: 下の帯（`plate`）とタブ（`tab`）を絵（`paint`）にした。

#    入口を2つ持つと「どちらが本道か」が言えなくなる。
