# 放置で歩く1体 ── ⭐ **部品**（器は 160x160）
#
# ⚠️ 何体並ぶかは編成しだいなので、置く場所は描く側が決める（`Idle.cs`）。
# ⭐ ここが持つのは「1体をどう描くか」だけ。
#
# ⚠️ **敵は絵だけ反転**（作者の指示 2026-08-28）。⭐ 器ごと反転させると字まで裏返る
#    （`unit.txt` が既に一度踏んだ事故）。だから絵を2つ書き分ける ── `unit.txt` と同じ形。
#
# 🔴 **枠は 64 の倍数**（2026-08-29・作者の指示「枠のサイズを固定し共通化させる」）。
# ⚠️ 160 だった頃は、64ドットの種族が 256px・16ドットの種族が 64px で描かれ、
#    **同じ帯に4倍違う大きさで並んでいた**（作者の指摘「敵の表示サイズがバラバラ」）。
# ⭐ 192 なら 64ドットは 3px/ドット・16ドットは 12px/ドットで、**どちらも 192px**になる
#    （`SpeciesTable.ArtDots` と `LayoutDom.FitArtStyle` 参照）。
#
# 🔴 **128 → 192 に上げ、器いっぱいに置いた**（2026-08-30・作者の指示「小さい。
#    地面から浮いている」／敵は「位置ずれ。小さい」）。⭐ 戦闘の駒（`unit.txt`）と同じ 192
#    ── 同じ体が画面によって違う大きさに見えないようにする（枠の共通化の続き）。
# ⚠️ **余白を持たせない**（旧: 160 の器に 128 を置いて上下左右 16 空き）。器の下端＝足元に
#    なるので、`Idle.cs` は「地面の線 − 器の高さ」で置くだけで足が地に着く
#    ── 余白があると、その分だけ浮いて見える（それが「地面から浮いている」の正体）。
#  名前   種類    左   上    幅   高    付け足し
