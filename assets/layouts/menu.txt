# 輪の外のものをまとめた小窓 ── ⭐ ホームの右上の入口から開く
#
# ⭐ **遊びの輪の外にあるものだけを集める**（2026-08-29・作者の指示
#    「図鑑や保存などのボタンにしか使わないものを一か所にまとめ、
#    ホーム画面の帯を消した後の右上に」「右上は入口1つにして、押すと4つが開く」）。
#
# ⚠️ 遊びの輪（探索→潜入→戦闘→帰還）は**下の帯**が持つ。ここへ混ぜない。
#    ⭐ ここに来るのは「たまにしか押さないが、無いと困るもの」── 図鑑・控え・試練・編成。
#
# ⚠️ **以前はこの4つが3か所に散っていた**: 図鑑は上のバーの右肩・控えはホームの帯の右端・
#    試練と編成はホームの巣の菱形の真ん中。⭐ 上のバーを外したのを機に1か所へ寄せた。
#
# ⚠️ 覆いを押しても閉じない ── ⭐ 「閉じる」を目に見える形で置く
#    （`eggpicker` と同じ約束。閉じ方が画面のどこにも書いていない状態を作らない）。
#
#  名前   種類    左   上    幅    高    付け足し
dim      veil    0    0     1080  1920
panel    card    96   560   888   800
  title  label   32   32    824   56    size=40 anchor=upper-left text=そのほか
  # ⭐ 縦に4つ並べる ── 横に割ると1つ 200px で「パーティ編成」(6字)が入らない。
  #    ⚠️ 押しどころの下限は 112。隙間 16 で 4本＝112×4+16×3=496。
  book   button  32   112   824   112   size=34 tap=book text=図鑑
  trials button  32   240   824   112   size=34 tap=trials text=試練
  party  button  32   368   824   112   size=34 tap=party text=パーティ編成
  keep   button  32   496   824   112   size=34 tap=keep text=保存の控え
  close  button  32   640   824   112   size=34 tap=close text=閉じる
