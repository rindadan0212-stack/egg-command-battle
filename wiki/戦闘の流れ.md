# 戦闘の流れ

⭐ **ターン制ではなく、ゲージが満ちた個体から動きます。**
巣の親とボスは**1体**、道中の[雑魚](潜入.md)は**3体**で立ちはだかります。

## 画面の読み方

| どこ | 何が出るか |
|---|---|
| **上の帯** | ⭐ **親・ボスの HP と行動ゲージ**。1体だけの相手はここで読みます |
| 体の足元 | 味方と雑魚の HP・行動ゲージ。⚠️ 丸は**属性の色**（残量は帯の長さで読みます）|
| 技の札 | 名前・**Lv**・CT |

⭐ **技の札を押し続けると、その技の詳細が開きます**
（何をするか・威力・Lv を上げると何がどれだけ上がるか）。
⚠️ 使えない技（CT 中・自分の手番でない）でも開けます。

## 決めること

手番が回ってきたら、決めるのは2つです。

| | |
|---|---|
| **どの技を使うか** | 3枠から1つ。⚠️ CT 中の枠は押せません |
| **誰に当てるか** | ⭐ **体を押すと狙い先になります**（四隅にカギ括弧が出ます）|

⭐ **敵の狙い先と味方の狙い先は別々に覚えます。**敵を選んだまま強化を押しても、
強化は味方に飛びます。⚠️ 選ばなかったときは、
攻撃と弱化は**一番 HP の低い敵**、手当ては**一番弱った味方**、
伸ばす札は**そのステが一番高い味方**へ落ちます。

⚠️ **相手が1体のときは選べません**（選ぶ余地が無いため）。

## 行動順

各個体にゲージがあり、時間とともに溜まります。**満タン（5000）になった個体が動きます。**

```
1刻みで溜まる量 ＝ 275 ＋ その個体の速度
```

⭐ **速度が 0 でも 275 は溜まります。**止まってしまう個体は居ません。
⚠️ この「275」があるので、**速度だけを積んでも行動回数は青天井になりません**。

⭐ 同時に満ちた場合は、**ゲージが多いほうが先**です（満タンを超えた分は繰り越されます）。

## CT（クールタイム）

技を使うと、その枠は**自分が何回か行動するまで**使えなくなります。

⚠️ 数えるのは「経過時間」ではなく **自分の行動回数**です。
⭐ **枠1（通常攻撃）の CT は常に 0** なので、他が全部 CT 中でも必ず打てる札が残ります。

## 決着

| | |
|---|---|
| 勝ち | 相手を全員倒す |
| 負け | こちらが全員倒れる |
| 引き分け | **300行動**に達する |

⚠️ **スタンで飛ばした手番も 300 に数えます**（全員スタンで止まらないように）。

## 敵が1体のときの補正

巣の親もボスも**1体**で立ちはだかります。そのままだと3対1で不利なので、補正が入ります。

| | |
|---|---|
| **HP** | 人数ぶんそのまま（3体ぶん） |
| **手数** | ⭐ **増える分は半分だけ**（3人ぶんの速さにはならない） |

⚠️ 手数を人数ぶんそのまま与えると、こちらが**まったく勝てなくなります**。
逆に据え置くと硬いだけの案山子になります。半分がその折り合いです。

⭐ **3体は倒すたびに弱くなりますが、1体は倒れるまで弱くなりません。**
だから同じ総量でも単体のほうが手強くなります。

## 運の要素

⚠️ **命中率も会心もありません。**
戦闘で運が絡むのは[弱化が通るかどうか](効果の種類.md)**だけ**です。

⭐ だから「同じ編成なら同じ結果」になります。負けたら編成を変えるのが正解です。

## 何が起きたかは体の上に出ます

⭐ **説明の欄はありません。**起きたことは、それが起きた体の頭の上に出ます。

| 出るもの | 意味 |
|---|---|
| 赤い数 | 受けたダメージ |
| 緑の `+数` | 回復 |
| 紫の数 | 毒で減ったぶん |
| `毒×2` / `リジェネ×1` | それが乗った（数は重なった枚数）|
| **`外れ`**（灰） | ⚠️ **弱化が外れた**（[効果の種類](効果の種類.md)）|
| `◇`（灰） | 免疫が弾いた。⚠️ 外れたのとは別物です |
| `◇`（濃） | シールドが1枚受け止めた |
| **`CT+2`**（赤）/ **`CT-1`**（緑） | 技の待ちが伸びた／縮んだ。⚠️ **増えるほうが不利**です |
| **`挑発2回`** | ⚠️ **この相手しか狙えない**。単体技を撃つたびに1つ減ります<br>（全体技や自分に掛ける技では減りません）|
| **`ガッツ`** | 一度だけ HP1 で耐えるようになった |
| **`免疫`**（緑） | すべての弱化を防ぐようになった |
| **`睡眠`** | 眠った。⚠️ 殴られると起きます |
| **`起きた`** | 殴られて睡眠が解けた |
| **`シールド2枚`** | 攻撃を枚数ぶん受け止める |
| **`ブロック`** | ⚠️ 外から受け取る回復と強化を弾かれている |
| **`弾いた`**（灰） | ブロック中に回復・強化が来て、不発になった |
| **`剥がした`** | 強化解除・強化強奪が乗っていた強化を落とした |
| **`復活`** | 蘇生で戻った |
| **`ゲージ+20%`** / **`ゲージ-20%`** | 次の手番までの進みが動いた |
| `▲攻撃` / `▼防御` | ステが上がった／下がった |
| `✖` | 手番を飛ばされた |

⭐ 1手で複数起きたときは**上へ積まれます**（重ねて読めなくしません）。
