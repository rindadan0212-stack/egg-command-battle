# 潜入

巣に入ると**分かれ道のあるすごろく**があります。一番奥に卵、その手前に親が居ます。

⭐ **目的は、親が帰ってくる前に卵まで辿り着くこと。**

## さいころの振り方

1. ⭐ **振る** ── さいころが画面の真ん中で**立体で転がります**。
   目が決まると、その面がこちらを向いて**しばらく止まります**
2. ⭐ **行ける先が光ります** ── そこを**押す**と進みます
3. ⭐ 駒は **1マスずつ踏みながら**進みます

⭐ **行ける先が1つしかなければ、押さずにそのまま進みます。**

⭐ さいころの目は **1〜6**。⭐ **出た目のぶん、きっかり進みます**
（分かれ道でも途中で止まりません）。⚠️ 卵に着いたときだけ、目が余っていてもそこで止まります。

### ⭐ 光っていないマスには行けません

⚠️ 通れない関門は、**そもそも光りません**。
⭐ だから「どこへ行けるか」は見ればわかります ── 鍵の絵も、道を選ぶ札もありません。

## 上の帯に出ているもの

| | |
|---|---|
| **さいころの絵** | ⭐ 並んでいる数が、**あと何回振れるか**。使ったぶんは空のさいころに変わります |
| **卵まで N マス** | ⭐ いま居るところから、**一番短く行ったときのマス数**。振れる回数と直に見比べられます |
| **剣・心・盾と数** | ⭐ **いま払える額**（攻撃・HP・防御）。⚠️ 関門のマスに出ている絵と数は、**これと同じ物差し**なので、そのまま見比べられます |

⭐ 財布の数は、関門で払うと**その場で減ります**。
⚠️ ▲▼ が効いている間は**色が変わります**（▲ は明るく、▼ は暗く）── 増減こみの
「いま出せる額」が出ているので、⭐ **▲ が切れる前なら、切れたあとより多く払えます**。

## さいころを振ったあと

⭐ 駒の上に**残りの歩数**が出て、1マス進むごとに減ります。
⭐ 出た目のぶん、きっかり進んでいることが数えずに分かります。

⭐ 駒はマスを踏むたびに**潰れて伸びます**。
⭐ **関門を踏んだときだけ、一拍おいて光ります** ── そこが一番「払った甲斐」のある所です。

⭐ 止まったマスが ▲ / ▼ なら、上がった量が**その場に浮きます**。

## 盤の形

⭐ 盤は**縦にスクロール**します。奥に何があるかは、上へなぞれば見えます。

⭐ 道は**その場ごとにばらばら**です。1本のところもあれば、
⭐ **横に最大4本**まで広がるところもあります。分かれ道の数も本数も決まっていません。

⭐ **線は交わりません。**どのマスからどこへ行けるかは、線をなぞれば必ず分かります。

⚠️ **どの道も同じマス数です。**道の形は選べても、進む距離は変わりません。
⭐ 距離を伸ばすのは、**マスがくれるもの**のほうです。

### ⭐ 一番大事な決まり

⚠️ **どのマスも、ただ入れます。**通せんぼは1つもありません。

⭐ 選択は「どの道を通るか」ではなく、**どのマスに止まるか**です。

## ⭐ 素のままでは、まず届きません

⭐ **何も拾わず、何も払わずに卵へ届くのは 2割**ほどです。

⚠️ 足りないぶんは、盤の上で取り戻します:

| | |
|---|---|
| **関門でステを払う** | ⭐ 振れる回数か、その場で進むマスが増える |
| **雑魚を倒す** | ⭐ 只で振れる回数が1回戻る。⚠️ ただし負ければそこで終わり |
| **▲ を拾う** | ⭐ ステが上がって、**払えなかった関門が払えるようになる** |

⭐ **速度に振った編成なら、そもそも払わずに届きます**（そろえた編成の 1.2〜1.4倍が目安）。

## 関門 ── 払うと対価がもらえるマス

⭐ 関門は**マス**です。他のマスと同じ大きさで、**1マスとして数えます**。

⚠️ **払わなくても入れます。**払えば有利になるだけです。

| 段 | 払う量（そろえた編成に対して）| もらえる回数 |
|---:|---|---:|
| ★1 | 14% | +1 |
| ★2 | 28% | +1 |
| ★3 | 42% | +2 |
| ★4 | 56% | +2 |
| ★5 | 70% | +3 |

⭐ 回数の代わりに「**その場で N マス進む**」をくれる関門もあります。

⚠️ **払ったぶんは、その潜入のあいだ戻りません。**⭐ ステは財布です。

くわしくは [関門](関門.md)。

## 道のマス

| マス | 起きること |
|---|---|
| **関門** | ⭐ 払うと対価がもらえます。⚠️ 払わなくても通れます |
| **敵** | ⭐ その場で 4対4 の戦闘。**勝つと振れる回数が1回戻ります** |
| **▲** | ⭐ そのステが一時的に上がります（＝**払えなかった関門が払える**） |
| **▼** | ⚠️ そのステが一時的に下がります（＝払えるはずの関門が払えない） |
| 素通り | 何も起きません。⭐ **どれも要らないときの行き先** |

⭐ **奥へ行くほど、敵と ▲ が濃くなります。**
⚠️ 入口の近くは素通りが多め ── まだ何も拾っていないうちに終わらないためです。

⚠️ **止まったマスだけが効きます。**通り抜けただけのマスは何も起きません。
⚠️ 増減は**振った回数**で切れます。

⭐ **敵と ▲ は、関門を通らない道に厚く置いてあります。**
⭐ 敵を倒せば振れる回数が1回戻り、▲ を踏めばステが上がって**この先の近道が開く**ことがあります。

⚠️ ただし敵は戦闘です。**負ければそこで終わり**、勝っても傷と CT は残ります。
⭐ だから「回数が足りているうちは敵を避け、足りなくなったら賭ける」が筋になります。

## 振れる回数

```
振れる回数 ＝ 編成の速度の合計 ÷ (47 × 編成の人数)
```

⚠️ **誰が速いかは効きません。**4体でひとつの駒なので、合計だけが効きます。

⚠️ 盗まれた巣ほど**親が早く帰ってきます** ── 1回盗むごとに振れる回数が1回減ります
（[巣の寿命](巣の寿命.md)）。

## 失敗するとどうなるか

| | |
|---|---|
| 卵に届いた | 強奪成功。戦わずに卵を得ます。⭐ **質は落ちず、巣も残ります** |
| **敵に負けた** | ⚠️ そこで見つかります |
| 振り切って届かない | 親が帰ってきて戦闘 |

⚠️ **盤の途中で行き止まることはありません。**どのマスにも、ただ入れます。

⚠️ **戦闘には潜入に使った編成がそのまま持ち込まれます。**傷と CT も引き継がれます。

⚠️ **そして戦って倒すと、その巣は終わります**（[巣の寿命](巣の寿命.md)）。

⭐ つまり編成が「通れるか」と「勝てるか」に**同時に引っ張られます**。

## ⭐ 道は巣ごとに決まっています

同じ巣はいつ来ても同じ道です。⭐ 一度入って確かめてから、
**その道に噛み合う編成に組み替えて挑み直せます**。

⚠️ 壁だらけの巣に防御寄りの編成で行くと、**払える関門が1つもありません**。
