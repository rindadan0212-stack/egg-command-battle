# 潜入

巣に入ると**分かれ道のあるすごろく**があります。一番奥に卵、その手前に親が居ます。

⭐ **目的は、親が帰ってくる前に卵まで辿り着くこと。**

## 基本操作

1. **さいころを振る**（1〜6）
2. 出た目のぶん進む
3. **分かれ道に着いたら、どちらの道を行くか選ぶ**
4. 振れる回数を使い切って卵に届かなければ、親が帰ってきて戦闘

⭐ 盤は**縦にスクロール**します。奥に何があるかは、上へなぞれば見えます。

## 上の帯に出ているもの

| | |
|---|---|
| **のこり** | あと何回振れるか。⚠️ 0 になって届いていなければ見つかります |
| **壁 攻 / 床 HP / 重圧 防** | いま持っている量。⭐ **どの道を通れるか**はここで決まります |
| **とどく／卵まで N マス** | いま通れる道でいちばん短く行ったときの、間に合う確率 |

## 分かれ道 ── ここが遊びの芯

分かれ道からは**2本**出ています。それぞれ**違うステ**を要求します。

```
        ○─○─○─○─○      遠い道（5マス）  重圧 293 が要る
       ╱             ╲
   ●──●               ●──   ● が分かれ道
       ╲             ╱
        ○─○              近い道（2マス）  床 1,258 が要る
```

⭐ つまり選択はこうなります:

> **こっちの道は HP が足りない。でもあっちの道なら防御で通れる。**

⚠️ **要求は「持っていること」です。減りはしません。**
⭐ 代価は**道の長さ**のほう ── 遠回りは振れる回数を食います。

### 近い道と遠い道

| | 近い道 | 遠い道 |
|---|---|---|
| 長さ | **1〜2マス**＋合流 | **3〜5マス**＋合流 |
| 要求 | **重い**（寄せた編成でないと通れない） | **軽い**（たいてい通れる） |
| 道の中身 | ほとんど素通り | ⭐ **敵**と **▲** が多い |

⭐ **遠回りには理由があります。**敵を倒せば**振れる回数が1回戻り**、
▲ を踏めばステが一時的に上がって**この先の近道が開く**ことがあります。

⚠️ ただし敵は戦闘です。**負ければそこで終わり**、勝っても傷と CT は残ります。
⭐ だから「回数が足りているうちは敵を避け、足りなくなったら賭ける」が筋になります。

### ⚠️ どの道も通れないとき

そこで見つかります。⭐ **編成が足りていない**という負け方です。

⚠️ 遠い道の要求は軽くしてあるので、まともに育っていれば起きません。
起きたなら、そのステが薄すぎるということです。

## 道のマス

| マス | 起きること |
|---|---|
| **敵** | ⭐ その場で 3対3 の戦闘。**勝つと振れる回数が1回戻ります**（[関門](関門.md)） |
| **▲** | ⭐ そのステが一時的に上がります（＝**この先の道が開く**） |
| **▼** | ⚠️ そのステが一時的に下がります（＝予定していた道が閉じる） |
| 丸い節 | 分かれ道 |

⚠️ **止まったマスだけが効きます。**通り抜けただけのマスは何も起きません。
⚠️ 増減は**振った回数**で切れます。

## 振れる回数

```
振れる回数 ＝ 編成の速度の合計 ÷ 140
```

⚠️ **誰が速いかは効きません。**4体でひとつの駒なので、合計だけが効きます。

⚠️ 盗まれた巣ほど**親が早く帰ってきます**（[巣の寿命](巣の寿命.md)）。

## 失敗するとどうなるか

| | |
|---|---|
| 卵に届いた | 強奪成功。戦わずに卵を得ます。⭐ **質は落ちず、巣も残ります** |
| **敵に負けた** | ⚠️ そこで見つかります |
| **どの道も通れない** | ⚠️ そこで見つかります |
| 振り切って届かない | 親が帰ってきて戦闘 |

⚠️ **戦闘には潜入に使った編成がそのまま持ち込まれます。**傷と CT も引き継がれます。

⚠️ **そして戦って倒すと、その巣は終わります**（[巣の寿命](巣の寿命.md)）。

⭐ つまり編成が「通れるか」と「勝てるか」に**同時に引っ張られます**。

## ⭐ 道は巣ごとに決まっています

同じ巣はいつ来ても同じ道です。⭐ 一度入って確かめてから、
**その道に噛み合う編成に組み替えて挑み直せます**。

⚠️ 壁だらけの巣に防御寄りの編成で行くと、近道が1つも通れません。
