# 潜入

巣に入ると**すごろくの道**があります。一番奥に卵、その手前に親が居ます。

⭐ **目的は、親が帰ってくる前に卵まで辿り着くこと。**

## 基本操作

1. **さいころを振る**（1〜6）
2. 出た目のぶん進む
3. **振れる回数を使い切って卵に届かなければ、親が帰ってきて戦闘**

⭐ 上の帯に、決めるのに要る数が3つ出ています。

| | |
|---|---|
| **のこり** | あと何回振れるか。⚠️ これが 0 になって届いていなければ見つかります |
| **ちから** | 分かれ道を壊すのに払う量 |
| **とどく** | **このまま歩き通したら間に合う確率**。⭐ 隠していません |

## 振れる回数

```
振れる回数 ＝ 編成の速度の合計 ÷ 140
```

⚠️ **誰が速いかは効きません。**3体でひとつの駒なので、合計だけが効きます。

⭐ 道の長さは**巣の段だけ**で決まります（速い編成のために道が伸びたりはしません）。

## 分かれ道

道の途中に**何かが道を塞いでいる分かれ道**があります。

⚠️ **踏まなくても、通り過ぎようとすると止まります。**そこで選びます。

| 選ぶもの | 起きること |
|---|---|
| **壊す** | ⭐ **その分かれ道が飛ばすマス数だけ先へ出ます。**⚠️ ちからを払い、**残った目は捨てます** |
| **進む** | ⭐ ちからは減りません。残った目のぶんだけ歩きます |

⭐ **だから出目が小さいときほど、壊す価値が上がります。**
6 を振って1マス目で止まったなら、歩いたほうが得なこともあります。

⭐ 押しどころの下に、**どちらを選ぶと「とどく」がどうなるか**が並んで出ます。

### 値段

分かれ道は1本ずつ**飛べるマス数**と**値段**が違います。⭐ 割安な本も割高な本もあります。

⚠️ **払ったちからは戻りません。**財布はひとつなので、
どの分かれ道に使うかは道全体を見て決めることになります。

### 値引き ── 寄せた編成が効くところ

塞いでいる物には種類があり、**得意なステを厚く持っているほど安く済みます**。

| 塞いでいる物 | 効くステ |
|---|---|
| **壁** | 攻撃 |
| **床** | HP |
| **重圧** | 防御 |

上の帯に **`壁 攻 122%`** のように出ます。⭐ **100% がその段の並**です。
122% なら払う量は約 8割、50% なら約 2倍になります。

⚠️ [素質](ステータス.md)は1体につき3ステまでしか上限に届かないので、
**1本を厚くすると別の1本が薄くなります。**寄せた編成は、
噛み合う巣では強く、噛み合わない巣では通れません。

⭐ **道は巣ごとに決まっていて変わりません。**入って確かめてから、
編成を替えて挑み直せます。

## 道のマス

| マス | 起きること |
|---|---|
| **敵** | ⭐ その場で 3対3 の戦闘。**勝つと振れる回数が1回戻ります**（[関門](関門.md)） |
| **▲** | ⭐ そのステが一時的に上がります（＝しばらく特定の分かれ道が安くなる） |
| **▼** | ⚠️ そのステが一時的に下がります（＝予定していた分かれ道が届かなくなる） |
| なにもない | 素通り |

⚠️ 増減は**振った回数**で切れます。⭐ 効いているあいだに使い切るかどうかが問われます。

⚠️ **入口と卵の直前には何も置かれません。**

## 失敗するとどうなるか

| | |
|---|---|
| 卵に届いた | 強奪成功。戦わずに卵を得ます。⭐ **質は落ちず、巣も残ります** |
| **敵に負けた** | ⚠️ そこで見つかります |
| 振り切って届かない | 親が帰ってきて戦闘 |

⚠️ **戦闘には潜入に使った編成がそのまま持ち込まれます。**
速度に寄せて失敗すると、脆いまま戦うことになります。

⚠️ **傷と CT も引き継がれます。**道中の敵を倒すほど、親との戦いが苦しくなります。

⚠️ **そして戦って倒すと、その巣は終わります**（[巣の寿命](巣の寿命.md)）。
早く倒すほど、その巣から引き出せる総数が減ります。

⭐ つまり編成が「届くか」と「勝てるか」に**同時に引っ張られます**。
