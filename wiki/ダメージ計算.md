## ダメージ

```
ダメージ ＝ 攻撃力 × 威力倍率 × 14 × 550 ÷ (550 ＋ 防御) × 属性倍率
```

⭐ **攻撃力にまっすぐ比例します。**威力は「攻撃力の何倍か」です。
⚠️ ダメージは**最低でも 1**。0 にはなりません。

### 威力の段位

| 段位 | 攻撃力の |
|---|---|
| 小 | **×1.2** |
| 中 | **×1.5** |
| 大 | **×2.0** |
| 特大 | **×3.0** |

⭐ スキルレベルが1段上がるごとに **+10%**。

### 防御による軽減

| 防御 | 通るダメージ |
|---|---|
| 0 | 100% |
| 150 | 79% |
| 300 | 65% |
| 600 | 48% |
| 1,000 | 35% |
| 2,000 | 22% |

⚠️ **割り算にしていません。**`÷ 防御` にすると防御の低い相手にダメージが爆発し、防御 0 では割れません。
⭐ `550 ÷ (550 ＋ 防御)` なら 0 でも割れて、積むほど効きが飽和します。

⭐ 守備側の定数が大きいのは、3体が集中攻撃されるぶん防御が実質3倍働くからです。数字だけ見て「防御は効きが悪い」と読まないでください。

⚠️ **防御無視**の技は、防御を 0 として扱います（軽減なし）。

| | 値 |
|---|---|
| 属性 有利 / 不利 | ×1.5 / ×0.75 |
| 最大HP | ステの **HP × 105** |
| 基準（HP の桁に合わせる係数）| 14 |

⚠️ 基準 14 は式の中で**唯一意味の無い数**です。最大HP と 攻撃力 は桁が2つ違うので、どこかで橋を渡す数が要ります。
⭐ 技ごとに散らさず1箇所に置いてあります。

## 弱化が通る率

```
通る率 ＝ 技の素の率 ＋ (弱化命中 − 弱化耐性) ÷ 10 ＋ 属性 ＋ 特性
```

| | 値 |
|---|---|
| ステ差の割り算 | **÷ 10** |
| 属性 有利 / 不利 | **±15pt** |
| 特性「狙い澄まし」 | +20pt |
| 特性「意地」 | −20pt |
| 下限 / 上限 | **25% / 95%** |
| スキルレベル1段につき | +10pt |

⚠️ **素の率が 100% の効果は乱数を引きません**（必ず通ります）。
⚠️ 上限 95% は**スキルレベルのぶんを足したあとにも掛かります**。

⭐ **免疫**が付いている相手には、弱化は率に関係なく通りません。

|---|---|
| 攻撃力・防御力・スピードの UP / DOWN | **±30%** |
