# ダメージ計算

## 計算式

```
ダメージ ＝ 威力 × 1.667 × (20 ＋ 攻撃) ÷ (110 ＋ 防御) × 属性倍率
```

- **威力** … 技の段位で決まります（[技一覧](技一覧.md)）
- **攻撃** … 攻撃力。⚠️ 一部の技は**防御力**で伸びます
- **防御** … 受ける側の防御力
- **属性倍率** … 1.5 / 1.0 / 0.75（[属性](属性.md)）

⚠️ ダメージは**最低でも 1** です。0 にはなりません。

## 攻撃と防御の効き方

分子にも分母にも定数（20 と 110）が乗っているので、⭐ **どちらも積むほど効きが鈍ります**。

| | |
|---|---|
| **攻撃を積む** | 20 に足すので、序盤ほど伸びが大きい |
| **防御を積む** | 110 に足すので、⚠️ **効きが緩やか。ただし全ての攻撃に効く** |

⭐ **防御のほうが分母の定数が大きい**のは、3体が集中攻撃されるため
防御が実質3倍働くからです。数字だけ見て「防御は効きが悪い」と判断しないでください。

## 多段と盾

⭐ **盾は1回の攻撃につき1枚消費し、威力に関係なくその攻撃を完全に無効化します。**

```
盾2枚 に 100ダメージ×2回 → 2回とも無効。HPは無傷
盾2枚 に   1ダメージ×4回 → 2回無効、残り2回は通る
```

⚠️ つまり盾は**大きな一撃に滅法強く、手数に弱い**です。
⭐ 盾を持つ相手には[連撃・乱打](技一覧.md)が刺さります。
