# 効果の種類

技が持つ効果と、それが通るかどうかの決まりです。

## 効果の一覧

| 分類 | 効果 |
|---|---|
| **ステータス** | 攻撃力 UP/DOWN・防御力 UP/DOWN・スピード UP/DOWN |
| **HP** | 毒・リジェネ・HP割合回復・盾 |
| **行動** | スタン・CT短縮・CT延長・挑発 |
| **特殊** | ガッツ・免疫 |

⚠️ 持続するものの単位は **「その個体の行動回数」**です。経過時間ではありません。

## 効き目

| 効果 | 効き目 |
|---|---|
| ステータス系 | ⭐ **一律 ±30%**。ステの数値そのものに掛かります |
| 毒 / リジェネ | 1スタックにつき**最大HPの5%**／1行動。⭐ **重なります**（2重で10%） |
| HP割合回復 | ⚠️ 技ごとに割合が違います |
| 盾 | ⭐ 点数ではなく**枚数** |

⚠️ ステータス系の**掛け直しは上書き**です。積み上がりません。

## 通る確率

⭐ **弱化・状態異常・回復・盾などは外れることがあります。**
⚠️ **ダメージと強化（自分に掛けるもの）は必ず通ります。**

⭐ **効き目が大きい技ほど外れやすく**なっています
（「小さいが必ず通る」と「大きいが半分外す」が別の技として並んでいます）。

## 速度が確率に効く

⚠️ **相手に掛けるものだけ**、実際の確率が速度差で上下します。

| | |
|---|---|
| 自分が速い | 通りやすい |
| 相手が速い | 通りにくい |
| 動く幅 | 素の率から **±30ポイント**まで |
| 下限 / 上限 | **25% / 95%** |

⭐ だから **速度が高い個体は弱化役として強い**です。
⚠️ どれだけ速くても 95% までなので、確実にはなりません。

⚠️ 自分・味方に掛けるもの（回復・盾・ガッツ・免疫）は速度で動きません。
素の確率がそのまま賭けになります。

## 免疫が防ぐもの

⭐ **免疫はすべての弱化を防ぎます。**

| 弾く（＝弱化） | 弾かない |
|---|---|
| ステータス DOWN / 毒 / スタン / **CT延長・封じ** | ダメージ・挑発・自分に掛ける強化 |

⭐ **「弱化」の括りは3つを同時に決めています。**

| | |
|---|---|
| 免疫が弾くか | 弱化なら弾く |
| 速度差で確率が動くか | 弱化なら動く（±30pt） |
| [特性](特性.md)の狙い澄まし・意地が効くか | 弱化なら効く |

⚠️ CT を**縮める**技（自分に掛けるもの）は弱化ではありません。
**延ばす**技だけが弱化です。

## その他

- **スタン** … 手番を飛ばします。⚠️ 飛ばした手番も行動上限に数えます
- **挑発** … 味方への**単体攻撃**を引き受けます。⚠️ **全体攻撃は逸らせません**
- **ガッツ** … 致命傷を HP1 で耐えます。⚠️ 元から HP1 なら効きません
- ⚠️ **毒とリジェネのスタックに上限がありません。**重ね続けると青天井になります
