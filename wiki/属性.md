# 属性

**炎・水・木**の3すくみです。

## 3すくみ

```
炎 → 木 → 水 → 炎
```

（炎は木に強く、木は水に強く、水は炎に強い）

## 倍率

| | 倍率 |
|---|---|
| 有利なとき | **×1.5** |
| 不利なとき | **×0.75** |
| どちらでもない | ×1.0 |

⚠️ **有利と不利は対称ではありません**（1.5 の逆数は 0.667 ですが、0.75 にしてあります）。
⭐ 対称にすると不利側の被害が大きすぎて、**属性だけで勝敗が決まってしまう**ためです。

⚠️ それでも有利側と不利側の差は **2.0倍**です。編成全体が同じ属性だと押し切られます。

## 属性は個体が持つ

⭐ **種族ではなく個体ごとです。**炎のタマルも水のタマルも生まれます。
配合では、親のどちらかから受け継ぎます。

## 編成を混ぜるべきか

⚠️ **3体を同じ属性で揃えると危険です。**
相手が有利属性で揃っていた場合、実測で**勝率が 0%** になります。

⭐ 混ぜた編成どうしなら、実測で 53.3%（ほぼ互角）。
**属性は保険として混ぜておくのが安全です。**
