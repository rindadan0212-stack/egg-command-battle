# レアリティ

卵には ★1〜★5 の**希少さ**があります。
⭐ **この★が、ほぼ全ての物差しです。**まずここを覚えると迷いません。

## ★が決めるもの

| | |
|---|---|
| **孵る個体の強さ** | 素質の合計が決まります（下表） |
| **孵るまでの時間** | ★が高いほど長く待ちます |
| **特性が付くか** | ★3以上の卵からだけ、[特性](特性.md)を持って生まれます |

| ★ | 素質の合計 | 孵るまで | 特性 |
|---|---|---|---|
| ★1 | 36 | 30秒 | 付かない |
| ★2 | 57 | 2分 | 付かない |
| ★3 | 78 | 10分 | **付く** |
| ★4 | 99 | 30分 | **付く** |
| ★5 | 120 | 2時間 | **付く** |

⚠️ 素質の合計には ±3 のばらつきがあります。

## ★はどこで決まるか

⭐ **巣の段階が中心**です。深い巣ほど高い★が出ます。

- 段階を中心に **±1** ばらつきます（浅い巣でも稀に上の★が出ます）
- ⭐ **入手経路では変わりません。**盗んだ卵も倒して得た卵も、★の出方は同じです

## 孵すか、素材にするか

⭐ 卵には**2つの使い道**があります。

| | |
|---|---|
| **孵す** | 待った先に強い個体が手に入る |
| **素材にする** | いますぐ[スキルレベル](スキルレベル.md)を上げられる |

⚠️ **★5は「2時間待って強い個体」と「いま技を1段鍛える」の二択になります。**
高い★ほど、この判断が重くなります。

⭐ 目安: **★N の卵1個で、技を Lv(N−1) → Lv N に上げられます。**
