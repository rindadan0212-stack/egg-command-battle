# 図鑑

⭐ **ホームの右肩**の「図鑑」から開きます。

⭐ ここが答えるのは1つ ── **「この種族を狙うと、何が手に入るのか」**。
[特性](特性.md)も[枠1の技](技一覧.md)も**種族で決まっている**ので、
巣を選ぶ前に知りたいことが種族の側に集まっています。

## 何が載るか

⭐ **一度でも手に入れた種族**が載ります。

⚠️ 「いま持っている種族」ではありません。⭐ **[分解](分解.md)しても図鑑からは消えません。**
枠を空けるたびに図鑑が減るのでは、集めた記録になりません。

| | |
|---|---|
| 上の数 | ⭐ **手に入れた数 / 全部の数** |
| 手に入れた種族 | 絵・名前・[特性](特性.md)の名前。⭐ **押すと中身が開きます** |
| まだの種族 | ⚠️ 絵は影だけ、名前は **？？？**。押せません |

⭐ **まだの種族も枠だけ出ます。**出さないと「あと何種いるのか」が分からず、
集める目標になりません。

## 種族の中身

札を押すと開きます。

| 項目 | 中身 |
|---|---|
| **特性** | 名前 ―[働く場面](特性.md)、そして何をするか |
| **枠1** | ⭐ **この種族が必ず持つ技**（引きません）|
| **枠2の抽選** | ⭐ 孵るときに**ここから1つ引かれます** |
| **枠3の抽選** | 同上。⚠️ 枠2 とは**別の袋**です |

⭐ **技を長押しすると効果が出ます**（威力・CT・Lv を上げると何が上がるか）。

⚠️ **枠1 の CT は常に 0** です（[戦闘の流れ](戦闘の流れ.md)）。
図鑑の枠1 を長押ししても 0 と出ます。

## 載らないもの

| | なぜ |
|---|---|
| **属性** | ⚠️ 属性は**卵ごとに引きます**（種族に関係なく等確率）。種族の性質ではありません |
| **★** | ⚠️ ★は[卵](卵と孵化.md)の側の話です |
| **素質の数** | ⚠️ 個体ごとに違います。種族が決めるのは**配分**だけ（[種族一覧](種族一覧.md)）|
