## 6. セーブ

### ⚠️ web で新しく生まれる消失経路は、退避（eviction）ではない

| | なぜ Unity には無かったか |
|---|---|
| **同じゲームを2つのタブで開ける** | Unity は1プロセス。両方が20秒ごとに書いて**後勝ちで片方が消える** |
| **閉じる瞬間に書き込みが間に合わない** | IndexedDB は非同期。`pagehide` 中の完了保証がない |

⭐ 対策（**機能ではなく保存の一部として最初に作る**）:
- Web Locks か `BroadcastChannel` で**書き手を1タブに限る**。2枚目は読み取り専用
- `visibilitychange`/`pagehide` では **localStorage の写しを同期で更新**。起動時に新しいほうを採る

### 層

```
層3  ブラウザの外 : 書き出したファイル        ← ⭐ 本命
層2  localStorage : 同じ JSON を1本（同期）   ← 閉じる瞬間の保険
層1  IndexedDB    : 世代リング + persist()   ← 主
```

⚠️ 層1と層2は Safari では**同じカウンタで一緒に消えます**。ブラウザ内に「別の消え方をする場所」は事実上ありません。**ここが Unity との本質的な差**で、だから層3が本命です。

### ⭐ 実セーブは 10,893 バイト

（Version 1 / Seed −332550685 / Serial 1135 / Creatures 22 / Eggs 4 / **Rng 48語＝12系統×4** / Trials bane,halt / Seen 3種）

⭐ **10世代持っても 110KB。**圧縮も差分も要りません。世代は「直近／5分前／1時間前／1日前／1週間前」で間引くと、「少しずつ壊れていく」形にも耐えます。

### いまのセーブを持ち込む手順

1. **Unity を閉じてから**写しを取る（起動していると20秒ごとに上書き）
2. ⭐ **読み込みを書き出しより先に作る**
3. ⚠️ **変換の道具を書かない。**いまのファイルを**そのまま**読めることを合格条件にする（変換器のバグが移植のバグに化ける）
4. 検証: 同じセーブを Unity と web に読ませ、**12系統の乱数を1回ずつ引いて全部一致するか**
5. ⚠️ **Unity 側をすぐ消さない。**数日遊んで問題が無いまで残す

### ⚠️ 移植で壊れやすい箇所

| | |
|---|---|
| **乱数の系統の並び** | `StreamsOf` の順序が**位置でしか表現されていない**（件数を書かない設計）。⚠️ TS なら `Object.values` の列挙順に頼ってはいけない ── **後から途中にキーを足しても動いてしまい、黙ってずれる** |
| 版 | ⭐ **1 のまま据え置く。**上げると Unity 版が読めなくなる。欄の追加では上げない（既に決定済み） |
| `Dictionary` の列挙順 | `Snapshot.cs:190,196` が保存文字列を作っている。⚠️ 順が変わると `App.Save()` の「同じなら書かない」がすり抜け、**20秒ごとのフル書き込みへ退行** |

### APK

⭐ **Capacitor + Filesystem プラグイン**を推奨（保存が**実ファイル**に戻る＝いまの `persistentDataPath` とほぼ同じ）。⚠️ TWA は保存の性質が web のままで、この論点を何も解決しません。

### ⭐ 場面（fixture）を3つ

| 場面 | これが無いと見えないもの |
|---|---|
| いつもの | ─ |
| **空** | 「？？？」／`_detail.SetActive(false)`／「空き（自動で埋まる）」 |
| 🔴 **あふれ** | ⭐ **本命。**最長の名前・最大の桁・上限の件数 ── 315対252 も、50体も、さいころ12個超も**全部これでしか見えません** |

⚠️ **作者が Unity Editor を使わなかった理由の半分がこれです。Prefab は空の姿しか見せないので、開いても「壊れる場面」が一度も出てこない。**

### 検査の見せ方

⚠️ **文字列の一覧を出さない**（作法「嘘の警告を出す道具は、そのうち誰にも読まれなくなる」）。⭐ 不備は**盤の上に、その形で**描く:

| 不備 | 見せ方 |
|---|---|
| 字の重なり | ⭐ 重なった矩形だけを赤で塗る |
| 親からはみ出し | ⭐ 親の枠の、**はみ出した辺だけ**（作法「線は一辺だけ」と同じ約束） |
| 押しどころが低い | ⭐ 札の下に **112 の目盛り**（**足りない量**が見える） |
| 列が幅に入らない | ⭐ 要る幅の半透明の札を右へ突き出す |

⭐ **決めごと2つ**:
1. 不備があっても**保存は止めない**（止めると「直すために保存できない」）。代わりに**不備0でないと `Converted` に入れられない**
2. ⚠️ **「この不備は嘘だ」を押す口を付けない。**誤検知を見つけたら**道具のほうを直す**
