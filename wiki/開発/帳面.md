# 帳面 — 技・種族・特性を手で書く

⭐ **C# を触らずに書くための入口。**`sheets/` の3つの帳面を編集し、`sim sheet` に検査させてから実装へ入れます。

⚠️ **帳面は遊びの出所ではありません。**ここを直しただけでは何も変わりません。
出所は今までどおり `Skills.cs` / `Species.cs` / `Trait.cs` の表です。

> **なぜ読み込みにしないのか**
> ゴールデンと 299件の検査が、コンパイル時に確定した表を踏んでいます。実行時に外部ファイルを
> 読む形にすると、照合が「その日のファイル」に左右されます。
> また表には手で書いた但し書き（挑発の狙い先の事故、全体技を1段下げる約束）が載っていて、
> 機械が表を丸ごと書き直すとそれが消えます。

⚠️ **コマンドは `unity-port\` で打ちます**（置き場所が `../sheets` 決め打ちのため）。

---

## 手順

⭐ **書き方は2つ。**出てくる文字列はどちらも同じです。

| | |
|---|---|
| **画面で書く** | `sheets/エディタ.html` をブラウザで開く（サーバ不要）|
| **文字で書く** | `sheets/技.txt` / `種族.txt` / `特性.txt` を直接編集する |

| | すること |
|---|---|
| 1 | `dotnet run --project EggCommand.Sim -- sheet write` — 帳面を作る／整える |
| 2 | `... -- sheet html` — 編集画面を作り直す（**帳面の中身ごと焼き込まれます**）|
| 3 | 画面か文字で編集する |
| 4 | `... -- sheet check` — 検査する |
| 5 | `... -- sheet code` — 貼れる C# が出る |
| 6 | 出た C# を表に入れて `dotnet test` → `... -- wiki` |

### ⚠️ `write` は何をするか

**「実装で上書き」ではなく「実装と突き合わせて整える」**です。

| 帳面の1件 | `write` の扱い |
|---|---|
| 実装にある id | 実装から作り直す（＝表を直した結果が反映される）|
| ↑ に手で足した `メモ` / `効果 = 自由記述` / `//` コメント | **そのまま持ち越す** |
| ↑ に手で直した本文（CT・威力など）| ⚠️ **消えます**（実装が正なので）|
| 実装に無い id | **1文字も触らず**末尾へ残す |

⭐ つまり「書きかけ」は安全です。⚠️ 危ないのは**実装済みの技の本文を帳面で直すこと** ── それは C# の表を直してください。

### ⚠️ 画面を作り直すタイミング

`sheet html` は**そのときの帳面を焼き込みます**。テキストを手で直したら、`sheet html` を打ち直すか、画面の **「帳面を開く」** で読み込んでください。古い画面のまま保存すると手直しが消えます。
⭐ 帳面が読めなかったときは、画面が赤くなって**保存を止めます**。

## 編集画面（`sheets/エディタ.html`）

| 場所 | できること |
|---|---|
| 左の一覧 | **技／種族／特性**の切り替え・絞り込み・新しく作る／複製／削除 |
| 雛形 | 攻撃技 / 弱化技 / 支援技 / 回復技 / 複合技 / 速さで殴る / ランダム / 味方全体 / 割合で削る / 弱化を治す / **まだ書けない** |
| 効果 | プルダウンで種類を選ぶと、**その種類に要る欄だけ**が出る。↑で並べ替え |
| CT | **数値欄。いくつでも書けます**（上限で縛りません）|
| 枠2・枠3 | ⭐ **棚から袋へドラッグ**。袋どうしで移動、棚へ戻すと外れる。押しても入ります |
| 姿 | **16×16 を押して塗る**（引きずれます）。全部消す／左右反転／実寸の見本 |
| 色 | 色見本を押して選ぶ。1組目が通常色、2組目からが変異色 |
| **説明の下書き** | ⭐ **効果から文を組んで出します。**「この文にする」で説明欄へ入り、あとから手で直せます |
| メモ | ⭐ **書式で書けないことを日本語で。**`write` を跨いで残ります |
| 最下部 | **帳面ではこう書かれます** ── 保存される文字列そのまま |

### 出し方

| ボタン | すること |
|---|---|
| **この1件をコピー** | いま見ている1件を帳面の書き方でクリップボードへ ── ⭐ **貼って渡すのが一番速い** |
| **保存** | ⭐ **触った柱だけ**ダウンロード。⚠️ `sheets/` に上書きしてください |
| **帳面を開く** | 手で直した `.txt` を画面へ読み込む（中身で見分けます）|

### ⭐ 説明の下書き

**文法は固定で、効果を入れると自動で組み上がります。**

```
〈狙い先〉〈助詞〉〈効果の文〉…する
```

| 例 | |
|---|---|
| `効果 = ダメージ 威力:中 依存:攻撃` | 敵1体**を**攻撃する |
| `効果 = ダメージ 威力:小 依存:スピード` | 敵1体**に**スピードで伸びる攻撃をする |
| 上に `効果 = 毒 スタック:1 ターン:4 確率:75` を足す | 敵1体に毒を75%の確率で4T付与**し**、攻撃する |

⭐ 助詞は効果ごとに変わります ── **付与するものは「〜に」、増減させるものは「〜の」、素の攻撃だけ「〜を」。**
⭐ ダメージは**最後に回ります**（状態を付けてから殴る、という起きる順に合わせるため）。
⚠️ **勝手に上書きしません。**「この文にする」を押したときだけ説明欄へ入ります。新しく作った技には最初から入っています。
⚠️ 効き目（±30% など）は**ゲーム全体で固定**なので文に書きません。技ごとに変わらない数を毎行書くと、変わる数（確率・持続）が埋もれるためです。

⭐ 出所は `SkillText.Describe`（図鑑と技一覧が使っているのと同じ関数）。画面の写しは自己検査が57技ぶん突き合わせています。

### ⚠️ 自己検査

帯の左に **「⭐ 自己検査 71件一致」** と出ます。**画面の JavaScript が C# と同じ答えを出しているか**を毎回突き合わせた結果です（書式・手ぶん・読み書きの3つ、実装済みの技と特性ぶん）。
⚠️ **赤くなったら保存しないでください。**C# を直して `sim sheet html` を打ち直します。

## 書き方

⭐ 1件 ＝ `# 技 <id>` / `# 種族 <id>` / `# 特性 <id>` で始まる1かたまり。
⭐ 行は `札 = 中身`。⚠️ 区切りは `=` だけ（`:` は効果の中で使うため）。
⭐ `//` で始まる行と空行は読み飛ばします。
⭐ 全角の `＝ ： ０-９ ＋ －　` はそのまま書いても通ります。
⚠️ id は**英小文字で始め、英小文字・数字・ハイフン**だけ（C# の名前になるため）。

### 技

```
# 技 poison-all
名前 = 毒・全体
説明 = 敵全体が行動するたびに削れる
型 = デバフ
CT = 5
狙い = 敵全体
効果 = 毒 スタック:1 ターン:4 確率:60
メモ = 何を書いてもよい
```

| 札 | 中身 |
|---|---|
| 型 | アタック / サポート / デバフ / ヒール |
| CT | ⭐ **上限なし。**⚠️ 5 を超えると検査が理由を添えて言うだけ（蘇生・全体大技・味方全体の大回復は 7 まで黙る）|
| 狙い | 敵1体 / 敵全体 / **敵のだれか1体** / 味方1体 / **味方全体** / 自分 / 倒れた味方 / **倒れた味方全体** / 最も弱った味方 |
| 効果 | 何行でも。**書いた順に効きます** |

### 効果の書き方

種類のあとに `札:値` を**好きな順で**並べます。

| 種類 | 札 |
|---|---|
| ダメージ | `威力:` 小/中/大/特大 ・ `依存:` **攻撃/防御/スピード** ・ `発数:` N ・ `防御無視` |
| 強化 / 弱化 | `ステ:` 攻撃力/防御力/スピード ・ `ターン:` N ・（弱化のみ `確率:` N）|
| 毒 / リジェネ | `スタック:` N ・ `ターン:` N ・ `確率:` N |
| **HP割合** | `割合:` **±N** ・ `確率:` N ── ⭐ ＋で回復、**−で最大HPの割合ぶん削る** |
| 蘇生 | `割合:` N ・ `確率:` N |
| **解除** | `個数:` **±N** ・ `確率:` N ── ⭐ ＋で強化を剥がし、**−で弱化を剥がす**（毒やスタンを治す）|
| シールド / 強化強奪 | `個数:` N ・ `確率:` N |
| スタン / 睡眠 / ブロック / ガッツ / 免疫 | `ターン:` N ・ `確率:` N |
| 挑発 | `回数:` N ・ `確率:` N |
| CT | `増減:` ±N ・ `確率:` N |
| ゲージ | `割合:` ±N ・ `確率:` N |
| **自由記述** | ⭐ **そのあとは何を書いてもよい** |

⚠️ **確率はダメージと強化には付きません。**下限は 20（それ未満は実装が切り上げます）。
⚠️ 数える札（ターン・スタック・個数・回数・発数）は 1 以上。
⚠️ HP・弱化命中・弱化耐性は強化も弱化もできません（戦闘に修正枠がない）。

### ⭐ 書けないことに当たったら

```
効果 = ダメージ 威力:小 依存:攻撃
効果 = 自由記述 倒れている味方1体につき威力を1段上げる（最大で特大）
メモ = 遺志の特性と組ませたい。3体編成なので最大+2段
```

⭐ **帳面は塞がずに通します。**⚠️ ただし実装した扱いにはならず、検査が ✍️ として数えます。
⚠️ 手ぶんにも数えません（「自由記述ぶんは数えていません」と出ます）。

### 種族

```
# 種族 kibane
名前 = キバネ
枠1 = attack-twice
基礎 = HP:90 攻撃力:110 防御力:80 スピード:120 弱化命中:130 弱化耐性:70
枠2 = stun-strike taunt-long poison-all stun sleep
枠3 = strip-strike pierce-strike
姿 =
  ................
  ...11......11...
  （16行×16文字）
色 = #2e2418 #8fc96e #c8eaa8 #1a1410
```

| 札 | 中身 |
|---|---|
| 基礎 | 合計 **600**、うち弱化2本 **200**。⚠️ 揃えないと起動時の検査が落ちます |
| 枠2 / 枠3 | **技を並べるだけ**（型は書きません）。⚠️ 上限 **5件**。⭐ 狙える確率は 1/(枠2×枠3) |
| 姿 | 字下げした行が格子。`.` が透明、`1`〜`4` が色番号（1=輪郭 2=体 3=差し色 4=目）|
| 色 | 1行に**4つ**。1行目が通常色、2行目以降が変異色 |

⭐ 枠1 の技を枠2・枠3 に入れてよい（孵化のとき自動で外れます）。⚠️ 外すと空になる書き方は通りません。

#### ⚠️ 袋の不変条件（型の縛りを外した代わり・2026-08-19）

| | |
|---|---|
| 袋は **5件**まで | ⭐ **狙える確率はここだけで決まります** |
| 1つの技は **2か所**の袋まで | ⚠️ 緩めると「どこで奪っても同じ」に戻ります |
| 枠2 と枠3 で同じ技を入れない | 片方が無駄になります |
| 2つの袋が同じ役割だけにならない | 分けた意味が無くなります |

⭐ 古い書き方（`枠2 = デバフ / stun-strike …`）も読めます。型は黙って捨てられます。

### 特性

```
# 特性 mirror
名前 = 写し身
働く場面 = 相手が強化を得たとき
すること = 相手が強化を得たら、自分にも同じ強化が乗る
噛み合うもの = 強化解除・強化強奪・意地
メモ = 場面が新しい。持続は相手と同じで、重ねがけは上書きでよい
```

⚠️ **特性の効き目は表から組み立てられません。**`Battle.React` に手で書くものです。
⭐ だからここは「何を作りたいか」を渡す欄で、**文章でかまいません**（作者の指示）。
⭐ `働く場面` は一覧から選べますが、**一覧に無い場面を書いてもよい** ── 検査が「`TraitWhen` に足して割り込み先を作る必要がある」と言うだけです。
⭐ 数値や条件は `メモ` に書いてください。そのまま実装の指示になります。

## 検査が言うこと

⭐ **4色に分かれます。**

| 印 | 意味 |
|---|---|
| 🚧 | そのままでは実装にできない（id の形・読めない効果・色の数など）。`code` が止まります |
| ⛔ | ⭐ **貼ると起動時の検査（`Skills.Audit` / `SpeciesTable.Audit`）が落ちます** |
| ✍️ | 手で書く必要がある（自由記述・メモ・新しい特性の場面）|
| ⚠️ | 通るが気になる（CT が長い・型と中身が食い違う・合計が他と違う）。**止めません** |
| 🗑 | 帳面から消えているもの ── ⚠️ **実装からは消えません**。表から手で消してください |

⭐ ⛔ は **Core の `Faults()` をそのまま呼んで**います。規則を帳面用に書き写していないので、片方だけ古くなることがありません。

### ⭐ 手ぶん

実装に無い技には、`sim turnvalue` と同じ算数で「何手ぶんか」が出ます。1.00 が「枠1 で殴るのと同じ値打ち」。

```
⭐ いま在る57技の帯: 0.15（防御力UP）〜 4.80（全体連撃）
大爆発             4.00 手ぶん  CT5  ダメージ 4,072×1×3体
```

⚠️ **決め打ちのしきい値では叱りません。**比べる相手は**いま在る技の帯**で、外に出たときだけ印が付きます。
⭐ 勝率ではなく算数なので、AI の癖に左右されません（[強さの測り方](技術と運用.md)）。

## ⚠️ この道具が踏んだ穴（同じ形を繰り返さないために）

| 穴 | 直し方 |
|---|---|
| 語彙を2か所に書く | **enum から引く**（`Skills.LabelOf`）。`依存:スピード` が黙って攻撃依存になっていた |
| 書式を JS と C# の2か所に書く | **自己検査で毎回突き合わせる**。許容は 1e-9（0.005 にしていたとき実バグが 0.0049 で素通りした）|
| 検査規則を帳面用に写す | **`Faults()` を呼ぶ**。写すと必ず片方が古くなる |
| 読めない行を捨てる | **原文のまま自由記述として残す**。捨てると黙って別の技になる |
| 語を言い換える | **前の語を `Aliases` に残す**。書いたものを壊さない |
| 上書きで整える | **手で足した行を持ち越す**。自由記述とメモが `write` のたびに消えていた |
| 打つたびに画面を作り直す | **導かれるものだけ描き直す**。1文字ごとに入力欄が作り直され、**フォーカスが外れて書けなかった** |
