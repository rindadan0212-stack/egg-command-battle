# 盤の生成と検査

⚠️ **これは実装側の決めごとです。**プレイヤーからは見えません。
⭐ ここが崩れると「解けない巣」が出荷されます。（旧 Wiki §6 から移設）

### ⭐ 盤の作り方 — 検査を生成の内側に置く

⚠️ **解ける巣かは目で見て分からない。**関門とリレーが入って、盤の良し悪しは走らせないと出ない。

| 決めごと | なぜ |
|---|---|
| **出荷は `MakeValidatedField` だけ**。素の `MakeField` は検査を通らない盤も返す | ⚠️ 検査を生成の外に置くと、悪い出目がそのまま出る |
| **合否は「解が在るか」ではなく「通る角度が何度あるか」**（下限 6度） | ⚠️ 幅1度の針の穴を「解けます」と報告していた。プレイヤーには運が悪いとしか見えない |
| 検査の相手は**参照編成**（段階ごとの想定・育成ぶん込み） | ⭐ 関門の鍵は盤の外（編成）にある。**参照編成で解けないのはバグ / プレイヤーの編成で解けないのは仕様** |
| **関門の要求は参照編成から導く** | ⚠️ 手で書いた表は必ずいつかずれる（段1 で実際にずれた） |
| **空ける車線を出口から逆算**してから塞ぐ | ⭐ 一番奥の関門は親の隙間と同じ側を空ける。揃えないと最後の一投が盤を横断させられる |
| 駄目なら**振り直す・8回で打ち切る・一番マシなものへ落ちる** | Brogue が湖20回・machine10回で打ち切るのと同じ |
| 探索は**投げる回数に上限**（`SearchBudget`）＋ **卵の方角から試す** | ⚠️ 上限が無いと1枚 7.2秒。順序が悪いと上限内に見つからない |
| 種は **(巣の id, 盗んだ回数)** だけから作る | ⚠️ 挑むたびに引くと、画面を出入りするだけで盤を選び直せる |

⭐ 実測（巣 120通り × 段階5 × 盗まれた回数4 ＝ **2400枚**）:
**検査に落ちたまま出荷した盤 0件** / 平均 6〜20度 / 最低 6度 / 最遅 670ms。

⚠️ **1つの種で通ったことは、ランダム化した生成が安全な証拠にならない。**
本番で効くのは珍しい悪い出目のほうで、それは数を撃たないと出てこない（`sim genstress`）。

⚠️ **画面に段階も素質も出さない**（姿だけ）。「入ってみないと分からない」が
発射フェーズの緊張の一部で、先に数字を見せると台無しになる。

**卵の質**: 倒して奪うほうが良い。差は段階が上がるほど開く
（段階1 で 4.8 / 段階3 で 10.9 / 段階5 で 17.1）。
⭐ **格上ほど「倒す」の価値が上がる**ので、育てて挑み直す動機になる。

### 変異の確率の実装（段D で判明）

ARK の公表値 7.31% / 0.184% / 0.00156% は、**2.5% を3回振る**と完全に一致する。

```
1回以上 = 1 - 0.975³        = 7.314%
ちょうど2 = 3 × 0.025² × 0.975 = 0.183%
ちょうど3 = 0.025³            = 0.00156%
```

⭐ 個別に確率を置くより素直で、**値が食い違う余地が無い**。実測 7.3192% / 0.1867% / 0.0013%。
