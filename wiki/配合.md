# 配合

⭐ **2体が卵に還ります。⚠️ 両親は失われます。**

## 役割

| | |
|---|---|
| **巣の卵** | ⭐ **新しいものを手に入れる唯一の入口**。ランダムで広い |
| **配合** | ⭐ **持っているものを尖らせる唯一の出口**。2体を失う |

⚠️ 配合は消費なので、続けるには探索に戻るしかありません。

## 子に引き継がれるもの

| | どうなるか |
|---|---|
| **素質の上限** | ⭐ **1代進むごとに上がります**（1ステ +1・合計 +3）|
| **素質の合計** | ⭐ 両親の平均。⚠️ **素では増えません** |
| **素質の配分** | ⭐ 形は両親の平均。⚠️ **育てた分**が「両親がともに高いステ」へ寄ります |
| 種族 | 50% でどちらかの親 |
| 技 | ⭐ **両親の4枠から2つ**を抽選 |
| 得意・不得意 | ⭐ **4本それぞれ**、親のどちらかから（[得意と不得意](得意と不得意.md)）|
| 属性 | 親のどちらかから |
| 色 | ⚠️ **継ぎません。**孵るときに引き直します |
| [特性](特性.md) | ⚠️ **継ぎません。**子の**種族**で決まります |
| **育てた分** | ⭐ **1/4 が子の生まれつきに変わります** |

⭐ **育てた労力は消えずに次の代へ渡ります。**これが Lv MAX の2体を失う対価です。

## ⚠️ 上限が上がっても、それだけでは強くなりません

⭐ **配合するたび、素質の上限が上がります**（1代につき1ステ +1・合計 +3）。
⚠️ ですが**中身は「両親の平均 ＋ 育てた分」でしか増えません**。

| どう配合したか | どうなるか |
|---|---|
| 育てずに配合を繰り返す | ⚠️ **枠だけ広がって、中身は据え置き** |
| 毎代きっちり育ててから配合 | ⭐ 中身が上限に張り付いていく |

⭐ つまり**上限は「入れ物」で、育成が「中身」**です。両方やって初めて伸びます。

⭐ **尖らせたいなら、同じ形どうしを掛けてください。**
育てた分は「**両親がともに高いステ**」へ寄って乗るので、
同じ形を重ねるほどその形が濃くなります。

⚠️ 形の違う親を掛けると、伸びしろが両方へ分かれて**丸くなります**。
⭐ 万能寄りにしたいときはそちらを選んでください。

⚠️ **素質の合計は配合では増えません。**増やせるのは巣の卵と変異だけです。
配合だけで際限なく強くなることはありません。

## 変異

⭐ 配合のたびに **2.5% の抽選を3回**引きます。当たった回数だけ変異します。

| | 値 |
|---|---|
| 抽選 | **2.5% × 3回** |
| 1回あたり | 素質の合計 **+2**、1ステの上限 **+1** |
| 変異の上限 | **20回**まで（血統全体の天井） |

⭐ **変異だけが素質の上限そのものを押し上げます。**
変異が出ると**体の色が変わります**。

⚠️ **両親とも変異を20回以上重ねていると、子に変異が出ません**（際限なく強くならないように）。

## ⚠️ 失われるもの

配合すると個体そのものが消えるので、以下も一緒に失われます。

- **[スキルレベル](スキルレベル.md)に注ぎ込んだポイント**
- 育てた分（⭐ ただし 1/4 は子の生まれつきになります）

⭐ 「この個体で行く」のか「配合の材料にする」のかを先に決めておくと無駄がありません。

## 親の札に出るもの

⭐ **遺伝するものはすべて出します。**選ぶ前に比べられないと、配合が博打になります。

| | |
|---|---|
| 名前・Lv・実値4本 | 得意は緑、不得意は赤 |
| 技3枠 | ⭐ 配合で狙うのは主にここ |
| **偏り**（▲▲▲▼▼▼） | 遺伝します（[得意と不得意](得意と不得意.md)）|
| **特性** | ⚠️ 子の**種族**のものになります（[特性](特性.md)）|
