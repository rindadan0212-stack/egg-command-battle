# はじめに

**欲しい卵を奪い、育て、配合して、理想の個体を作り、壁を越えるゲームです。**

## 1周の流れ

```
ボスに挑む → 勝てない → 「何が足りないか」を考える
  → 必要な技・ステを持つ親の巣へ行く
  → 巣に潜入：卵に届けば強奪（巣は残る）/ 見つかれば戦闘（勝てば卵、ただし巣は終わり）
  → 卵を孵す or 素材にしてスキルを鍛える
  → 放置で溜めた EXP と、戦闘で得た育成ポイントで育てる
  → 配合（両親は失われます）→ 次の世代
  → 理想個体で編成を組む → ボスへ戻る
```

## 何が勝敗を決めるか

⭐ **単純な強さではなく「壁に対して噛み合っているか」です。**

同じ強さの編成でも、相手の属性・技・関門に噛み合っていなければ通りません。
逆に、数字が低くても噛み合っていれば通ります。

⚠️ だから「とにかく強い個体を1体作る」より、**3体の役割を組む**ほうが効きます。
実測でも、速度に全振りした編成より役割を分けた編成のほうが幅広く通ります。
⭐ [素質](ステータス.md)は**3つまでしか伸ばせません**（ステは6種）。
「攻め＋弱化命中」「守り＋弱化耐性」のように、何と何を組むかを選ぶことになります。
