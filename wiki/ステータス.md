# ステータス

**HP / 攻撃 / 防御 / 速度 / 弱化命中 / 弱化耐性** の6種です。

## 何に効くか

| ステ | 効くところ |
|---|---|
| **HP** | 倒れるまでの余裕。[潜入](潜入.md)で**床**をどけられるか |
| **攻撃** | [ダメージ](ダメージ計算.md)。潜入で**壁**を壊せるか |
| **防御** | 受けるダメージ。潜入で**重圧**をどけられるか。⚠️ 一部の技は**防御でダメージが伸びます** |
| **速度** | [行動の速さ](戦闘の流れ.md)。潜入で**さいころを振れる回数** |
| **弱化命中** | 相手に掛ける[弱化](効果の種類.md)の**通りやすさ** |
| **弱化耐性** | 相手から掛けられる弱化の**通りにくさ** |

⭐ **弱化命中と弱化耐性は打ち消し合います。**「自分の弱化命中 − 相手の弱化耐性」の差で、
弱化の通る率が上下します（[効果の種類](効果の種類.md)）。

⚠️ **速度は弱化に効きません。**速度は行動順と、潜入で振れる回数だけを決めます。

⭐ **攻撃・HP・防御は[潜入](潜入.md)でひとつの財布になります。**
厚く持っているステの[関門](関門.md)ほど安く済むので、
⚠️ **1本に寄せると、別の1本の関門が通れなくなります。**

## 素質・育成分・実値

```
実値 ＝ 種族の基礎値 ＋ 素質（生まれつき） ＋ 育てた分
```

| | |
|---|---|
| **種族の基礎値** | [種族](種族一覧.md)ごとの配分。⭐ **合計はどの種族も同じ** |
| **素質** | 生まれつき。⚠️ **変えられません**。卵の★で合計が決まります |
| **育てた分** | 戦闘の報酬で伸びます（[育成](育成.md)） |

⭐ **弱化命中と弱化耐性にも種族差があります。**攻める種族は命中寄り、守る種族は耐性寄りです。
⚠️ ただし**この2本の合計はどの種族も同じ**なので、片方に寄せた種族は逆側が薄くなります。

### 画面での見え方

BOX と[配合](配合.md)の札では **「素質」と「強化」の2列**で出ます。

| 列 | 中身 |
|---|---|
| **素質** | 種族の基礎値 ＋ 素質（得意・不得意の ±15% 込み）＝ **育てる前の実値** |

⚠️ **弱化命中・弱化耐性にも種族の基礎値があります。**
基礎値の合計は全種族 **600**（HP・攻撃・防御・速度で 400 ＋ 弱化2本で 200）で、
差は配分だけです。

⚠️ **HP だけ桁が違います。**HP は戦闘で削られる量そのものを出しているので、
他のステより2桁ほど大きくなります（攻撃力 300 の個体が HP 35,000、など）。

## 数の目安

| ステ | よく育てた個体 | とてもよく育てた個体 |
|---|---|---|
| HP | 30,000〜50,000 | **約 100,000** |
| 攻撃力 / 防御力 | 300〜600 | 約 1,000 |
| スピード | 200〜500 | 約 900 |
| 弱化命中 / 弱化耐性 | 200〜300 | 約 500 |

⭐ **弱化命中と弱化耐性に上限はありません。**この2つは引き算で打ち消し合うので、
耐性 200 の相手には命中 210 をぶつければ通ります。
⚠️ 上限があるのは**通る率のほう**で、どんなに差をつけても 25%〜95% の外には出ません。
| **強化** | 育てて**実値がいくつ増えたか** |

⭐ **足すと実値になります。**⚠️ 「素質」の列は生まれつきの数を実値の形で出しているので、
上の表の「素質（0〜40）」そのものではありません。

## 上限

| | |
|---|---|
| 1ステの上限 | **40** |
| 素質の合計上限 | **120**（＝1ステ上限の3倍） |

⭐ **合計上限が1ステ上限のちょうど3倍**なので、**得意を3つまで作れます**。
⚠️ ステは6本あるので、**3つ伸ばすと残り3つは薄いまま**です。万能は作れません。

⭐ ここで「攻めに全部」ではなく「攻め＋弱化命中」「守り＋弱化耐性」のような
**組み合わせ**を選ぶことになります。4体 × 3つ ＝ 9枠で編成を組む設計です。

⚠️ **全ステが高い万能個体は作れません。**継承で合計が上限を超えると、
**低いステから削られます**。高いステは残るので、特化は保たれます。

⚠️ 素質が 0 でも種族の基礎値は残るので、削られたステが完全に死ぬことはありません。
⚠️ 弱化命中・弱化耐性も同じで、素質を削られても種族の基礎値は残ります。

## どこに寄せるべきか

⚠️ **1体で全部やろうとしないでください。**上限があるので必ずどこかが薄くなります。
⭐ 4体で役割を分けるほうが、結果的に広い場面に通ります。

⭐ 弱化命中は「弱化を当てにいく個体」に、弱化耐性は「止められたくない個体」に寄せます。
⚠️ 弱化を持たない個体に弱化命中を振っても何も起きません。
