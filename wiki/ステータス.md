# ステータス

**HP / 攻撃 / 防御 / 速度** の4種です。

## 何に効くか

| ステ | 効くところ |
|---|---|
| **HP** | 倒れるまでの余裕。[潜入](潜入.md)のダメージ床を越えられるか |
| **攻撃** | [ダメージ](ダメージ計算.md)。潜入の壁を壊せるか |
| **防御** | 受けるダメージ。潜入の重圧エリアを越えられるか。⚠️ 一部の技は**防御でダメージが伸びます** |
| **速度** | [行動の速さ](戦闘の流れ.md)。弱化の通りやすさ。潜入の**飛距離** |

⭐ **速度だけは3つに効きます**（行動順・弱化・飛距離）。ただし飛距離は
「どの個体をいつ使うか」の資源でもあるので、多ければ良いとは限りません。

## 素質・育成分・実値

```
実値 ＝ 種族の基礎値 ＋ 素質（生まれつき） ＋ 育てた分
```

| | |
|---|---|
| **種族の基礎値** | [種族](種族一覧.md)ごとの配分。⭐ **合計はどの種族も同じ** |
| **素質** | 生まれつき。⚠️ **変えられません**。卵の★で合計が決まります |
| **育てた分** | 戦闘の報酬で伸びます（[育成](育成.md)） |

## 上限

| | |
|---|---|
| 1ステの上限 | **40** |
| 素質の合計上限 | **80**（＝1ステ上限の2倍） |

⭐ **合計上限が1ステ上限のちょうど2倍**なので、**得意を2つまで作れます**。
3体 × 2つ ＝ 6枠で編成を組む、というのがこのゲームの設計です。

⚠️ **全ステが高い万能個体は作れません。**継承で合計が上限を超えると、
**低いステから削られます**。高いステは残るので、特化は保たれます。

⚠️ 素質が 0 でも種族の基礎値は残るので、削られたステが完全に死ぬことはありません。

## どこに寄せるべきか

⚠️ **1体で全部やろうとしないでください。**上限があるので必ずどこかが薄くなります。
⭐ 3体で役割を分けるほうが、結果的に広い場面に通ります。
