## 1. ⭐ 一番の収穫 — 効果の分類体系

まもダンの約60種の効果は、**7つのカテゴリ**に整理されている。
⭐ **個別のスキル名を並べるより、この分類そのものが価値がある。**

| カテゴリ | 効果 |
|---|---|
| **回復・蘇生** | 単体回復 / 全体回復 / 蘇生 / 自動蘇生 / 復活 / 最大HP回復 / 継続回復 |
| **ゲージ・CT** | CT短縮 / CT延長 / ゲージ増加 / ゲージ減少 / ゲージ吸収 / それぞれの無効 |
| **強化** | 攻撃強化(大) / 防御強化(大) / 速度強化 / 強化解除無効 / 強化効果延長・短縮 / 強化状態強化 / 強化状態コピー |
| **弱化** | 攻撃弱化 / 防御弱化 / 速度弱化 / 弱化解除 / 弱化効果延長・短縮 / 弱化無効 / **弱化移し** / 弱化耐性増加 |
| **攻撃** | 単体 / 全体 / 連続 / 反撃 / 追撃 / **防御無視** / 会心 / **固定ダメージ** / ダメージ増加・減少・無効 |
| **状態異常** | 毒 / 猛毒 / スタン / 睡眠 / **挑発** / 封印 / 暗闇 / 沈黙 / 凍結 / 麻痺 |
| **防御・耐性** | 妨害免疫 / バリア / シールド / こらえる / 無敵 / 気迫 / 風の守り / 保護膜 |

⭐ **読み取れること**: 60種あるように見えて、実体は
「**何を・どれだけ・誰に・どう変える**」の掛け合わせ。
Wiki [技一覧](../wiki/技一覧.md) が既に定めている「スキルを個別にコードで書かない。
少数のプリミティブの組み合わせをデータで表す」と**同じ構造**。

## 2. ⭐ ゲージの仕組み（実装に直接効く）

出典: [ゲージとターン獲得（note）](https://note.com/jaaan203/n/ncd40c3a051b5)

- 速度が高いほどゲージの自然上昇が速い
- ⭐ **「超過ゲージ」がある。** 見た目は100%止まりだが、**内部では100%を超えて溜まり続ける**
- ⭐ **ターンを取るのは「内部ゲージが最も多い者」。速度ではない**
- **ターン獲得**という別の効果があり、これはゲージ段階を**飛ばして**即座に行動する
  （CT短縮とは別物。他者の内部ゲージがいくら多くても割り込める）

### 本作との差分

| | まもダン | 本作の現状 |
|---|---|---|
| 超過ゲージ | あり | ⭐ **あり**（`gauge -= GAUGE_MAX` で繰り越している） |
| 同時に満ちたときの順 | **内部ゲージが多い順** | ⚠️ **配列の並び順**（恣意的） |
| ターン獲得 | あり | 無し |

⭐ **採る価値があるのは「同時に満ちたら内部ゲージが多いほうが先」**。
今の並び順による決着は根拠が無く、繰り越したゲージが報われない。

## 3. スキルの継承（まもダンの「スキルサポート」）

出典: [スキルサポート（GameWith）](https://gamewith.jp/mamodan/497724)

- **2つ目のスキル**を別のモンスターに習得させる
- スキルレベル・ステータス+値・潜在解放・覚醒（半分の効果）が一緒に移る
- ⚠️ **同属性のみ**
- ⚠️ ~~**サポートに使ったキャラは編成できなくなる**（実質、素材として消える）~~
  → ⚠️ **これは誤りだった**（2026-08-18 に原文確認）。消えない。外すときにダイヤがかかるだけ。
  詳細は [まもダン_メタ分析_2026-08-18.md](まもダン_メタ分析_2026-08-18.md)
- ダイヤを払えば解除できる

### 本作との差分

| | まもダン | 本作 |
|---|---|---|
| 移し方 | **狙って直接移す**（素材を1体消費） | 配合で**両親の4枠から2つ抽選** |
| 制約 | 同属性のみ | 制約なし（種族を跨げる） |
| コスト | 素材が編成不可になる | 世代を1つ進める |

⚠️ **本作のほうが運の要素が強い。** まもダンは「狙った技を確実に付ける」代わりに
1体を潰す。本作は「引きたい組み合わせを狙う」緊張がある。
⭐ **どちらが良いかは遊んでみないと分からない**ので、今は変えない
（Wiki [配合](../wiki/配合.md) の「4枠から2つ抽選」を維持）。

## 4. 本作に足すなら何か

⚠️ **状態異常は Wiki [没案と未実装](../wiki/没案と未実装.md) に入っている**（v1）ので、下表からは外してある。

### 今のプリミティブ（5種）

`damage` / `heal` / `stage` / `gauge` / `cover`

### 足す価値がありそうなもの（優先順）

| # | プリミティブ | 何ができるようになるか | 理由 |
|---|---|---|---|
| 1 | **`ct`**（相手/自分の CT を増減） | CT短縮 / CT延長 | ⭐ **CT が本作の戦闘の芯**なのに、それを操作する手が1つも無い。「大技を早く撃つ」「相手の大技を遅らせる」という読み合いが生まれる |
| 2 | **`turn`**（即座に行動権を得る） | ターン獲得 | ⭐ ゲージ制の駆け引きが一段深くなる。まもダンでも別枠の効果として扱われている |
| 3 | **`shield`**（次のNダメージを肩代わり） | バリア / ダメージ減少 | 「かばう」と組むと壁役の幅が出る。回復と違い**先に置く**のが読み合いになる |
| 4 | **`cleanse`**（強化/弱化を消す・移す） | 強化解除 / 弱化解除 / 弱化移し | 段階（stage）を既に持っているのに、**消す手段が無い**。鈍足を掛けられたら終わり、になっている |
| 5 | `pierce`（防御無視） | 防御無視攻撃 | ⚠️ 本作は `DEF_SOFTEN=110` で高防御が非常に硬い。**硬い相手を崩す唯一の手**になりうる |

⚠️ **`revive`（蘇生）は入れない方がいい。** 本作は「死なない・保管枠有限」なので、
戦闘中の戦闘不能はその戦闘限りの話。蘇生を入れると持久戦が伸びるだけになる
（既に「1戦102行動」が課題に上がっている）。

### ⚠️ 足すときの注意

Wiki [効果の種類](../wiki/効果の種類.md) に「**3体同時 × スキル遺伝 × 属性3すくみ で検証が掛け算になる**」と書いてある。
プリミティブを足すたびに `npm run sim -- --party` と `--progress` を回して、
**均等ぞろいの優位が広がっていないか**を見ること。

## 5. 名前と数値をどうするか

⚠️ **まもダンのスキル名は使わない。**（[没案と未実装](../wiki/没案と未実装.md) / 販売予定）
⭐ 本作は既に**独自の命名**を持っている:

| 本作 | 効果 |
|---|---|
| たたかう / 強撃 / 薙ぎ / 殻打ち / 震撼 | 攻撃 |
| 迅速 / 守勢 | 強化 |
| 鈍足 / 足止め | 弱化・ゲージ |
| 手当 | 回復 |
| かばう | 肩代わり |

⭐ 3すくみを **牙 / 羽 / 鱗** にしてあるので、追加する技も
**生き物の部位や動作**から採ると世界観が揃う
（例: 爪・鱗立て・羽ばたき・威嚇・喰らいつき）。

⚠️ **数値は借りない。** 本作は `npm run sim` に当てて決める仕組みが既にある。
まもダンの CT 値は wiki が読めず取得できなかったが、**取得できても使わない**
（ダメージ式もステの尺度も違うので、そのまま入れても意味を持たない）。
